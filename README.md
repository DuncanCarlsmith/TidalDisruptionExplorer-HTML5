# Tidal Disruption Explorer (HTML5 port)

A browser-based port of the MATLAB Live Script
[Tidal Disruption Explorer](https://www.mathworks.com/matlabcentral/fileexchange/?q=carlsmith)
by Duncan Carlsmith.

This repo is **work in progress**. See `PROGRESS.md` for the current build state
and roadmap.

## What it does (when complete)

Interactive 2D simulation of a self-gravitating cluster of granular particles
disrupted by tidal forces from one or two massive sources. Demonstrates the
Roche limit, with separately-drawn 3D and disk-corrected Roche radii per star.
